# Seguridad

## Datos sensibles

Este proyecto puede usar cookies de YouTube para acceder a contenido que
requiere una sesión iniciada. **Nunca** publiques:

- Archivos `cookies.txt` o exportaciones del navegador.
- Tokens, contraseñas o archivos `.env`.
- URLs privadas, enlaces con firma o contenido de cuentas ajenas.

El archivo `.gitignore` ya excluye cookies, `.env`, descargas y archivos
temporales, pero revisa siempre `git status` antes de hacer un commit.

## Reportar una vulnerabilidad

No abras una *issue* pública para problemas de seguridad. Usa la pestaña
**Security → Advisories** del repositorio o contacta con
[@natsu-dev01](https://github.com/natsu-dev01) de forma privada.

Incluye una descripción del problema, los pasos para reproducirlo y el impacto
potencial.
